# Security

Please do not include credentials, personal viewing histories, database exports, or exploitable details in public issues. Use GitHub's private vulnerability reporting when enabled; otherwise contact the repository owner before sharing sensitive information.

Deployment configuration must block access to backend source, environment files, databases, backups, private keys, and operational notes. Keep user data outside the public static root where possible.

Third-party players run on external origins. Do not grant pop-up or top-level navigation privileges to new embeds by default. Validate the origin and payload before accepting player messages. Do not bypass upstream access restrictions.
